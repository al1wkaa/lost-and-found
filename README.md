# Lost & Found — найденыш вещей (Flask + Jinja2 + SQLite)

Сайт «потеряшек»: объявления о потерянных и найденных вещах, регистрация,
личный кабинет, поиск и фильтры. Вёрстка — из папки `lost_found/site`,
шаблоны Jinja2 — в `templates/`, статика — в `static/`.

## Запуск

```bash
# 1. Виртуальное окружение (один раз)
python -m venv venv

# 2. Активация
# Windows (PowerShell/cmd):
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Запуск
python app.py
```

Сайт откроется на http://127.0.0.1:5000 . База `lostfound.db` создаётся
и наполняется справочниками автоматически при первом запуске (`db.py`).

## Страницы

| Адрес | Описание |
|---|---|
| `/` | Главная: герой, преимущества и лента активных объявлений из БД |
| `/items?type=lost` | «Пропажи»: поиск и фильтр по категориям (GET-параметры) |
| `/items?type=found` | «Находки» |
| `/item/<id>` | Страница объявления, контакты автора (только для вошедших) |
| `/register`, `/login`, `/logout` | Регистрация, вход, выход (POST) |
| `/add` | Подать объявление (только для вошедших) |
| `/dashboard` | Личный кабинет: активные и закрытые объявления, статистика |
| `/uploads/<файл>` | Фотографии объявлений |

## Структура

```
app.py               — маршруты и логика Flask
db.py                — SQLite: схема и справочники
templates/           — шаблоны Jinja2 (наследуются от base.html)
static/css/style.css — стили вёрстки (+ небольшой блок интеграции)
static/images/logo.png — логотип «Нашлось!»
uploads/             — фотографии объявлений
docs/integration-map.md — карта соответствия вёрстки и маршрутов
lost_found/          — исходная вёрстка и референсы (не изменяются)
```

Карта интеграции и список изменений бэкенда — в `docs/integration-map.md`.
