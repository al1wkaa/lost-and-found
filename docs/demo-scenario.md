# Сценарий демонстрации (5 минут)

Демонстрация на предзаполненной базе: `python seed_demo.py --reset`,
запуск `python app.py`, открыть http://127.0.0.1:5000.

Роли: **Аня** (demo1@example.com, потеряла наушники) и **Дима**
(demo2@example.com, нашёл наушники). Пароль у обоих: `demo12345`.
Показываем в двух окнах браузера (или быстро перелогиниваясь).

## Тайминг

### 0:00–0:30 — Гостевая часть
- Главная: герой, лента активных объявлений из базы (9 карточек,
  пагинация внизу).
- Страница объявления: контакты скрыты, вместо них «Войдите,
  чтобы увидеть контакты». Сразу видно правило сайта.

### 0:30–1:00 — Вход Ани и её объявления
- Вход под demo1@example.com.
- Личный кабинет: активные объявления, статистика, раздел
  «Предложенные совпадения» (у Ани есть совпадение по рюкзаку —
  показать можно позже).
- Меню: «Мои объявления» и «Профиль» появились только после входа.

### 1:00–2:00 — Дима нашёл наушники
- Выйти, войти как Дима, «Подать объявление»: тип «Нашёл»,
  категория «Электроника», место «Остановка», дата — позавчера,
  заголовок «Нашёл беспроводные наушники», описание, фото.
- После отправки — страница объявления; для автора видно, что
  система нашла совпадение («Возможно, эта вещь соответствует…»).

### 2:00–3:00 — Аня видит совпадение и подтверждает
- Выйти, войти как Аня. В кабинете в «Предложенных совпадениях»
  появилась находка Димы с оценкой системы.
- Открыть карточку совпадения: кнопки «Это моё» и «Не подходит»,
  контакты пока скрыты.
- Нажать «Это моё» — сообщение с контактами обоих участников
  («Контакты участников»), совпадение исчезает из предложений.

### 3:00–3:45 — Отклонение (на второй паре)
- У Димы в находках есть пара, которую можно отклонить: показать
  «Не подходит» на любом новом совпадении — сообщение «Совпадение
  скрыто», карточка больше не предлагается.
- Цель: показать, что ложные срабатывания легко убрать в один клик.

### 3:45–4:30 — Поиск, фильтры, профиль
- Поиск по слову «рюкзак», фильтр по категории, сброс фильтров
  кнопкой «Сбросить».
- Профиль: поменять имя или телефон, сохранить; показать смену
  пароля (без реальной смены — можно указать тот же пароль,
  форма попросит старый).

### 4:30–5:00 — Финал
- Кратко: почему это работает (алгоритм сам сводит людей,
  контакты открываются только после подтверждения).
- Сослаться на тесты (74 теста) и на `docs/matching-tuning.md`
  (алгоритм проверен на 189 парах демо-данных: 7/7 полнота,
  0 посторонних).

## Запасной план (если что-то не так)

| Проблема | Что делать |
|---|---|
| Совпадение не появилось у Ани | Открыть кабинет Димы — совпадение показывается и там; либо показать пару «рюкзак» из демо-данных (она есть всегда) |
| Не работает интернет/фото | Фото необязательно: совпадение считается и без него, форма принимает пустое поле |
| Случайно подтверждена не та пара | Не страшно: показать contacts-блок и продолжить; данные демо можно сбросить командой `python seed_demo.py --reset` после демонстрации |
| Забыли пароль демо-пользователя | Пароль у всех `demo12345`; пересоздать демо-данных `--reset` |
| Сайт упал с 500 | Перезапустить `python app.py` — база и справочники восстанавливаются автоматически; при полностью испорченной базе удалить `lostfound.db` и запустить заново, затем `seed_demo.py` |

## Ответы на частые вопросы

1. **«Что если кто-то соврёт, что вещь его?»** — Контакты открываются
   обоим только после подтверждения автором потери; дальше стороны
   договариваются сами. Проверку вещи по приметам лучше сделать
   при встрече — это заявлено как развитие (модерация, чат).
2. **«Как считается оценка совпадения?»** — Пять составляющих:
   категория 30, место 25 (соседнее 10), время до 20, текст до 15,
   фото 10; порог 60. Подробно и с пограничными случаями —
   `docs/matching-tuning.md`.
3. **«Почему SQLite, а не PostgreSQL?»** — Для учебного проекта
   и демонстрации SQLite достаточна и не требует сервера; схема
   простая и переносится на PostgreSQL. Ограничения честно
   перечислены в README.
4. **«Как защищены данные?»** — Параметризованные запросы, автоэкранирование
   Jinja2, CSRF-токены, хэши паролей, cookie HttpOnly/SameSite, ключ
   сессии только из переменной окружения, файлы фото проверяются
   по содержимому, контакты видят только вошедшие.
5. **«Что уже протестировано?»** — 74 автотеста pytest (алгоритм,
   фильтры, права, CSRF) плюс сквозные проверки на демо-данных:
   все 7 ожидаемых пар найдены, ни одной посторонней из 189.
